캠핑 자동 감시 - 설치 순서 (윈도우)

이 폴더에는 프로그램이 3개 들어 있습니다. 텔레그램을 쓰는 프로그램마다 별도 봇 1개씩 연결하세요.
별도로 4_화담숲 보조 도구도 있습니다. 화담숲은 현재 설정 저장/예매 화면 열기만 지원하며 잔여석 자동 조회·자동 선택은 미완성입니다.
한 번에 하지 말고 1단계가 끝까지 되는 걸 확인한 뒤에 2단계로 넘어가세요.

  1_연곡  = 연곡해변캠핑장 (로그인 없음)         <- 1단계
  2_갯골  = 갯골자연휴양림 오토캠핑장 (로그인 포함) <- 2단계
  3_미천골 = 국립미천골자연휴양림 오토캠핑장/야영데크 (별도 계정 설정) <- 3단계
  4_화담숲 = 입장권+모노레일 설정/예매 화면 열기 (자동 조회·선택 미완성)

각 폴더 안의 00_처음시작.txt 에 자세한 설명이 있고, 맨 아래에 "텔레그램 봇 만들기"가 있습니다.

공통 준비 (한 번만)
- 컴퓨터에 Python 설치: https://www.python.org/downloads/windows/  (Python 3.14.10 의 "Windows installer (64-bit)")
  설치 첫 화면 맨 아래 "Add python.exe to PATH" 꼭 체크 -> Install Now
- 폰에 텔레그램 앱 설치 + 전화번호로 가입
- 이 캠핑자동화 폴더를 바탕화면 등에 압축 풀기 ("모두 압축 풀기")

========== 1단계: 1_연곡 ==========
 [ ] 1-1 Start Camping.bat 더블클릭 -> 설치가 진행됨 (몇 분)
 [ ] 1-2 설치 끝에 "지금 정해져 있는 조건"이 화면에 나옴 -> 맞으면 Enter(그대로), 바꾸려면 e
         ※ 텔레그램이 아직 없으면 알림/리모컨 질문은 건너뜀 (1-5 후에 설정_보기_수정.bat 에서 켤 수 있음)
 [ ] 1-3 "열린 사이트와 조건..." 문구가 나오면 아직 Enter 누르지 말고 Ctrl+C 로 끄기
 [ ] 1-4 체험해보기.bat 더블클릭 -> "체험 성공!" 또는 "로그인/조회는 정상, 빈자리가 없음" 이 나오면 OK. 브라우저 창 닫기
 [ ] 1-5 연곡용 텔레그램 봇 만들기 (예: 이름 "아빠연곡", 아이디 papa_yeongok_bot) -> telegram_setup.py -> 폰에 "연결 테스트" 도착
 [ ] 1-6 설정_보기_수정.bat -> "텔레그램: 연결됨" 확인 -> 4번(아침 알림), 5번(폰 리모컨)을 켤지 정하기
         (※ 알림/리모컨은 컴퓨터가 켜져 있어야만 옴. 필요 없으면 끄거나 안 켜도 됨)
 [ ] 1-7 리모컨을 켰다면: 연곡 봇에 "도움말" -> 답이 옴 -> "시작" -> 브라우저 열림 + "감시 시작" 알림 -> "중지"
 [ ] 1-8 Start Camping.bat 로 직접 켜서 Enter -> 폰에 "감시 시작" 알림 -> Ctrl+C 로 끄기
 모두 "예"면 1단계 완료!

========== 2단계: 2_갯골 ==========
1단계가 끝난 뒤에 시작합니다. 봇은 1단계와 다른 새 봇을 만드세요(같은 봇이면 서로 방해합니다).
 [ ] 2-1 Start Camping.bat 더블클릭 -> 설치 -> 조건 확인 질문(그대로 Enter / 바꾸려면 e)
         (숲나들e 아이디/비밀번호는 이미 들어 있습니다)
 [ ] 2-2 "로그인 완료. 매달 4일 09:00 오픈..." 문구가 나오면 Ctrl+C 로 끄기
 [ ] 2-3 체험해보기.bat -> "체험 성공!"(빈 방 이름과 날짜 표시) 또는 "빈 방이 없음" 이 나오면 OK. 브라우저 창 닫기
 [ ] 2-4 갯골용 텔레그램 봇 만들기 (예: 이름 "아빠갯골", 아이디 papa_gaetgol_bot) -> telegram_setup.py ("교체할까요? YES") -> 폰에 "연결 테스트" 도착
 [ ] 2-5 설정_보기_수정.bat -> 4번(아침 알림: 매달 4일 아침 8시), 5번(폰 리모컨)을 켤지 정하기
 [ ] 2-6 리모컨을 켰다면: 갯골 봇에 "도움말" -> 답 -> "시작" -> "감시 시작" 알림 -> "중지"
 [ ] 2-7 Start Camping.bat 로 직접 켜서 Enter -> "감시 시작" 알림 -> Ctrl+C 로 끄기
 모두 "예"면 2단계 완료!

========== 3단계: 3_미천골 ==========
 [ ] 3-1 이 폴더의 00_처음시작.txt 확인 -> Start Camping.bat 실행
 [ ] 3-2 숲나들e 아이디/비밀번호를 로컬 입력창에서 설정 (기존 폴더의 개인정보는 복사하지 않음)
 [ ] 3-3 설정_보기_수정.bat: 3번 시설/자리, 6번 입실 날짜, 7번 1박/2박 변경
 [ ] 3-4 텔레그램을 쓰려면 미천골 전용 봇 연결 -> 4번 수요일 08:00 알림 / 5번 리모컨 선택
 [ ] 3-5 먼저 --check로 실제 로그인/조회 결과 확인 -> 원하는 조건으로 감시 시작
 미천골 기본값은 토요일·1박·2명·오토캠프장 전체 한 자리입니다. 선착순 오픈은 매주 수요일 09:00입니다.

========== 가장 중요한 주의 ==========
- 예약 버튼은 프로그램이 절대 누르지 않습니다. 자리가 잡히면 알림이 오고, 인증 숫자(캡차)와 마지막 [예약]은 직접 합니다.
- 알림과 폰 리모컨은 컴퓨터가 켜져 있어야만 동작합니다. (꺼짐/절전/덮개 닫힘 = 안 옴)
- 봇 토큰은 비밀번호입니다. 코덱스에게 알려주면 코덱스가 연결해 줍니다(코덱스는 괜찮음). 카톡 등 다른 사람에게는 보내지 마세요.
- 갯골의 숲나들e 계정은 지은 님과 같은 계정입니다. 지은 님과 동시에 켜면 서로 로그아웃될 수 있으니, 4일 9시에는 한 사람만 켜세요.
- 컴퓨터를 끄거나 절전으로 두지 말고(노트북은 전원 연결 + 덮개 열기), 브라우저 창/검은 창을 닫지 마세요.
