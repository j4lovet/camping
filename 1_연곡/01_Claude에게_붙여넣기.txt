---------- 복사 시작 ----------
나는 코딩 초보이고, 받은 연곡해변캠핑장 예약 보조 프로그램을 내 컴퓨터/계정에 설정하려고 한다.
처음 설치부터 단계별로 안내하고, 내 목표에 맞는 코드 수정과 테스트를 도와줘.

먼저 물어볼 것:
1. 내 운영체제(Mac/Windows), Python 설치 여부, 이 폴더 위치.
2. 원하는 날짜 범위/요일, 시설 번호, 숙박 일수, 한 자리만 필요한지.
3. 내 텔레그램 봇을 만들었는지. 토큰/채팅 ID를 AI 대화창에 요구하지 말 것.

초기 설정:
- 00_처음시작.txt를 읽고 내 환경에 맞춰 설명해줘. 한 단계마다 결과 확인 후 다음으로 진행해줘.
- 가상환경/requirements.txt/Playwright Chromium 설치를 안내해줘.
- 공식 @BotFather에서 내 봇 생성 → /start → telegram_setup.py로 로컬 설정을 안내해줘.
- 토큰은 getpass로 로컬 터미널에만 입력하게 하고, 다른 사람 .env나 상위 폴더 설정을 읽지 마.
- 본인 수신 대화 확인과 테스트 메시지 수신 확인을 거친 뒤 실행해줘.
- 나는 처음 실행할 때 예약 시도 없이 --check와 모의 테스트부터 하고 싶다.

코드 구조:
- camping_watch.py: 일정 조회, A구역 전체 중 빈자리 한 자리 선택, 다음단계, 인증/정보입력 화면에서 중단.
- site는 "A*"(전체), "A135"(한 자리), ["A142", "A135"](우선순위 목록) 지원. 설정 메뉴 8번에서 변경. A101~A153만 허용. available_site는 목록 순서를 우선하고 실제 화면의 표시명/ID를 확인한 뒤 한 자리만 선택함. 목록 밖으로 대체하지 말 것.
- camping_common.py: 비밀정보 없는 공통 유틸, 텔레그램 전송, 상태 저장.
- camping_settings.json: 기본 조건은 A구역 전체(site: A*)/1박/토요일. checkin_dates에 입실 날짜를 지정하면 요일보다 우선하며 nights는 1 또는 2. 설정 메뉴 6번에서 날짜, 7번에서 박수 수정. 화면의 시설명과 실제 선택 ID를 읽어 한 자리만 선택함(월은 자유, 오픈 시각 빠른 확인·9:30 알림 포함).
- telegram_setup.py: 본인 봇 검증, 개인 대화 선택, 테스트 전송 확인 후 로컬 .env 저장.
- test_camping_watch.py, test_setup.py: 네트워크/실제 점유 없이 실행하는 모의 테스트.
- Start Camping.bat: Windows 가상환경 설치/실행(이 폴더는 Windows로 포팅됨). 맥용 원본은 별도 폴더.

조건을 바꿀 때 반드시 확인:
- target_dates의 고정 검증, ENTRY의 최초 달력 월, 날짜 생성/만료 처리.
- inspect의 구역 버튼 값, roomcode/rKey ID, 표시 시설명 검증.
- verify_dates의 퇴실일/박수, attempt의 단일 선택과 날짜 재검증.
- handoff_phase의 정보입력 화면/선택시설/이용일자/점유 타이머 검증.
- 알림 문구, 실행 배너, 문서, 테스트의 기존 날짜/시설 하드코딩.
- 시설 내부 ID는 표시 번호와 같다고 추측하지 말고 공식 UI에서 직접 확인할 것.
- 2박은 실제 날짜변경 달력에서 입실일·퇴실일을 클릭하고 기간 전체의 가용성을 조회함. 2026-11-03에 공개 UI로 11/28~11/30의 2박 표시까지 검증(자리 선택/다음단계 미실행). UI 변경 시 재검증할 것. 3박 이상은 아직 미지원. 단순 문자열 치환으로 기간을 속이지 말 것.
- Windows 포팅 내용: 잠금(msvcrt), 절전 방지(SetThreadExecutionState), 감시 프로세스 탐색/종료(psutil), 자동 실행(작업 스케줄러/시작프로그램). 맥에서만 시험했고 Windows 실기기 검증은 아직 필요함.

안전한 동작 유지:
- 정상적인 공개 UI 클릭만 사용. 비활성 버튼 강제 클릭, 숨겨진 예약 API, 대기열/인증/접근 제한 우회 금지.
- CAPTCHA는 직접 풀게 멈추고 알림. 자동으로 읽거나 답을 입력하지 말 것.
- 이름/전화번호/약관/본인인증/최종 예약·결제는 내가 직접 한다.
- 다음단계 진입 전 대상 날짜/시설/박수/한 자리만 선택됐는지 검증한다.
- 정보입력 화면과 임시점유 안내를 구분해서 알림. 인증 화면이나 클릭만으로 선점 성공이라 하지 말 것.
- pending 상태를 먼저 저장하고, 불명확한 결과/접근 제한이면 반복 예약하지 말고 멈출 것.
- 기존 점유를 자동 해제하거나 상태 파일을 무조건 삭제하지 말 것.
- 조회 간격을 무작정 줄이거나 계정/IP를 바꿔 제한을 피하지 말 것.

완료 기준:
