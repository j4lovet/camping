연곡해변캠핑장 자동 감시 (윈도우용)

하는 일
- camping.gtdc.or.kr 에서 토요일 1박, 2명, A구역 전체 중 한 자리가 열리거나 취소로 비면 "다음 단계"까지 눌러 줍니다.
- 인증(캡차)이 나오면 멈추고 알려줍니다. 인증 숫자, 이름/전화/약관, 최종 예약·결제는 반드시 직접 합니다.
- 캡차/대기열/접근 제한은 우회하지 않습니다.
- 평소 대기 시간은 15초(취소표 대비). 오픈 전후 미오픈 날짜는 1초, 오픈일 09:59:58~10:00:20에는 매진 표시가 나와도 해당 날짜의 대기 시간을 0.1초로 유지합니다. 실제 조회 주기에는 화면 처리·응답 시간이 더해집니다.
- 로그인이 필요 없는 사이트라서 계정 정보는 들어 있지 않습니다.

처음 한 번만 (설치)
1. Python 3.10 이상 설치: https://www.python.org/downloads/windows/
   설치 첫 화면에서 맨 아래 "Add python.exe to PATH"를 꼭 체크하세요.
2. 이 폴더 전체를 원하는 곳(예: 바탕화면)에 둡니다. (압축 파일이면 먼저 "모두 압축 풀기")
3. "Start Camping.bat"를 더블클릭합니다. 처음에는 필요한 것을 자동으로 설치하느라 몇 분 걸립니다.
   - "Windows의 PC 보호" 파란 창이 뜨면 "추가 정보" -> "실행"을 누르세요.
4. 텔레그램 알림은 선택입니다. 설정하려면 y, 건너뛰려면 Enter. (건너뛰면 알림이 화면에만 뜹니다.)
   - 처음이면 이 파일 맨 아래의 "텔레그램 봇 만들기 · 연동"을 먼저 따라 하세요. (폰에 텔레그램 설치부터 설명되어 있습니다)
   - 봇 토큰은 비밀번호입니다. 코덱스에게 알려주는 건 괜찮지만, 다른 사람에게 보내거나 화면 캡처로 공유하지 마세요.
5. 사이트가 열리면 조건을 확인하고 검은 창에서 Enter를 눌러 감시를 시작합니다.

쓸 때
- 날짜가 열리기 전(오전 10시 전)부터 켜 두면 됩니다. 평소에도 켜 두면 취소표를 잡습니다.
- 컴퓨터를 끄거나 절전/최대절전으로 두지 마세요. 노트북이면 전원을 꽂고 덮개는 열어 두세요.
- 브라우저 창과 검은 창(터미널)은 닫지 마세요.
- 빈자리가 잡히면 알려줍니다. 브라우저에서 인증 숫자를 입력하고 이름/전화/최종 예약까지 직접 진행하세요.

폰으로 켜고 끄기 / 아침 알림 (선택, 텔레그램 설정 후)
- 폰 리모컨: 폴더에서 주소창에 cmd 를 입력해 검은 창을 연 뒤  .camping-venv\Scripts\python.exe install_remote.py
  이후 본인 봇에 시작 / 오픈 / 중지 / 상태 / 도움말 을 보내면 됩니다. (오픈 = 오늘 열리는 날짜만 감시) 컴퓨터는 켜져 있어야 합니다.
- 오픈일 9:30 알림: .camping-venv\Scripts\python.exe install_reminder.py
- 삭제: 위 명령 끝에 --remove 를 붙이세요.

조건 바꾸기 (설정_보기_수정.bat 더블클릭)
- 8번: A사이트 전체/특정 번호 선택.
  1) 전체: A구역 전체에서 화면에 먼저 나오는 빈자리 한 곳을 선택합니다.
  2) 특정 번호: A135 또는 135처럼 한 개, A135 A136 A142 또는 135,136,142처럼 여러 개를 입력합니다.
  여러 번호는 입력 순서가 우선입니다. 첫 번호가 마감이면 다음 번호를 확인하며 지정 목록 밖으로는 선택하지 않습니다.
  지원 번호는 A101~A153입니다. 같은 번호는 한 번만 적용하며 B/C 등 다른 구역은 입력할 수 없습니다.
  사이트를 바꿔도 날짜·박수·인원·알림 설정은 유지됩니다.
- 6번: 원하는 입실 날짜 지정/해제. 예: 2026-11-20 2026-11-27
  여러 날짜는 후보이며 그중 한 날짜에 한 자리만 진행합니다. 퇴실일이 아니라 입실일을 적으세요.
  날짜를 지정하면 요일 조건 대신 지정한 날짜만 조회합니다. '해제' 입력 또는 1번에서 요일 변경 시 요일 조건으로 돌아갑니다.
  지난 날짜는 자동 제외하며, 모두 지났더라도 다른 날짜를 대신 예약하지 않습니다.
- 7번: 숙박 일수를 1 또는 2로 변경. 예: 11/20 입실 + 2박 = 11/22 퇴실.
  2박은 실제 사이트의 날짜변경 달력에서 입실·퇴실을 선택합니다. 같은 자리에 2박 전체가 가능할 때만 진행합니다.
- 날짜와 박수를 바꾼 뒤 감시를 껐다 다시 켜면 적용됩니다. 아직 변경하지 않으면 기존 토요일 1박 조건을 유지합니다.

직접 설정 파일을 고칠 때 (camping_settings.json, 메모장으로 열기)
- checkin_dates: 입실 날짜 목록. 예: ["2026-11-20", "2026-11-27"]. []이면 요일 조건 사용.
- nights: 1 또는 2. 입력한 모든 후보 날짜에 같은 박수를 적용합니다.
- weekdays: 요일. 0=월 ... 5=토 6=일. 예: 금요일 토요일이면 [4, 5]
- max_lookahead_days: 오늘부터 며칠 앞까지 볼지. 지정 날짜도 이 기간 내에 들어와야 조회됩니다.
- headcount: 인원.
- site: 전체는 "A*", 한 자리는 "A135", 여러 자리는 ["A135", "A136", "A142"]처럼 지정합니다.
- 바꾼 뒤에는 감시를 껐다가 다시 켜세요.

확인만 해보기 (선택/예약 동작 없음)

끄기: 검은 창에서 Ctrl+C 또는 브라우저 창 닫기. 예약 진행 중에는 누르지 마세요.
중요: 실제 실행 중인 감시가 있으면 중복 시작을 막습니다. 감시가 종료된 뒤 남은 진행 기록은 다음 실행에서 data/state_history에 백업하고 초기화합니다. 예약 조건과 개인정보 설정은 유지됩니다. 이 기록은 실제 예약 접수 여부를 뜻하지 않으므로 사이트 예약 내역은 직접 확인하세요.

자리 선택: 설정_보기_수정.bat → 8) A/B사이트 선택에서 설정하세요.
- 1) A전체 / 5) B전체 / 6) A·B전체. 지원 번호: A101~A153, B201~B246.
- 2) 특정 번호만: B220 B221 또는 B220 A135처럼 입력한 순서를 유지합니다. 135는 A135, 220은 B220으로 인식합니다.
- 3) 지정 자리 → 해당 구역 나머지 전체. B자리만 지정하면 B구역만, A·B를 함께 지정하면 두 구역에서 찾습니다.
- 4) 지정 자리 → 지정 범위 → 해당 구역 나머지 전체. 예: 1순위 B220 A135 / 2순위 B210~B230 A110~A148.
- 범위는 작은 번호부터 찾고, 이미 우선순위에서 확인한 자리는 중복 확인하지 않습니다. 변경 후 감시를 다시 시작하세요.

빈자리 선택 후 인증/정보입력 단계에서는 예약 브라우저를 앞으로 띄웁니다.
별도 팝업이나 알림음은 없으며, 기존 텔레그램/화면 안내는 유지됩니다.

==================== 설정 보기/수정 · 체험해보기 · 알림 ====================
[설치할 때 나오는 질문] Start Camping.bat 를 처음 실행하면 설치 뒤에 아래를 차례로 물어봅니다.
  1) 지금 정해져 있는 조건(요일, 인원, 자리 등)을 화면에 보여주고 "이 조건 그대로 쓸까요?"
       Enter = 그대로 쓰기 / e = 바꾸기
  2) (텔레그램이 연결돼 있으면) 아침 알림을 켤까요? / 폰 리모컨을 켤까요?
       필요 없으면 n 을 누르면 꺼 둡니다.
       ※ 알림은 그 시각에 컴퓨터가 켜져 있어야만 옵니다. 컴퓨터가 꺼져 있거나 절전이면 알림이 안 옵니다.
  이 질문은 처음 한 번만 나옵니다. 나중에 바꾸고 싶으면 아래 "설정_보기_수정.bat" 를 쓰세요.

[설정_보기_수정.bat] 더블클릭하면
  - 지금 조건과 알림/리모컨이 켜져 있는지 한눈에 보여줍니다.
  - 번호를 눌러 요일, 인원, 볼 기간, 입실 날짜(6번), 숙박 일수(7번), A사이트 전체/번호(8번)를 바꾸고, 아침 알림과 폰 리모컨을 켜고 끌 수 있습니다.
  - 바꾼 조건은 감시를 껐다가 다시 켜면 적용됩니다.

[체험해보기.bat] 더블클릭하면 (먼저 Start Camping.bat 로 설치를 한 번 끝내 두세요)
  - 지정 날짜/요일 조건을 풀고, A구역과 설정한 숙박 일수는 유지한 채 "지금 열려 있는 아무 날짜"로 프로그램이 어떻게 움직이는지 보여줍니다.
  - 빈자리를 찾으면 캡차(인증) 직전까지 가서 멈추고 "체험 성공!" 이라고 알려줍니다. 이게 실제 예약 날 일어나는 일입니다.
  - 지금 열려 있는 빈자리가 없으면 "로그인/조회는 정상, 빈자리가 없어서 끝까지는 못 감" 이라고 알려줍니다. 나중에 다시 해보세요.
  - 끝나면 브라우저 창을 닫으세요. 체험 기록은 진짜 감시와 따로 저장되어 영향을 주지 않습니다.
  - 체험 중 이름/전화/결제까지 진행하지만 않으면 예약되지 않습니다. 혹시 예약이 접수됐다면 결제하지 말고 사이트에서 취소하세요.

==================== 텔레그램 봇 만들기 · 연동 (처음 한 번, 약 10분) ====================
빈자리 알림을 폰으로 받고 폰에서 시작/중지를 하려면 본인 텔레그램 봇이 필요합니다. (건너뛰어도 감시는 되고, 알림이 컴퓨터 화면에만 뜹니다.)
봇은 프로그램마다 따로 만드세요. 갯골과 연곡을 둘 다 쓰면 봇이 2개 필요합니다. (같은 봇을 두 곳에서 쓰면 둘 다 안 됩니다.)

[A. 텔레그램 설치/가입 - 폰]
 1) 앱스토어/플레이스토어에서 Telegram(파란 종이비행기)을 설치합니다.
 2) 전화번호 입력 -> 인증번호 입력 -> 이름 정하면 가입 완료. (PC용 텔레그램은 없어도 됩니다.)

[B. 봇 만들기 - 폰 텔레그램에서]
 3) 맨 위 검색창에 BotFather 입력 -> 이름 옆에 파란 체크(V)가 있는 공식 계정을 열고 "시작"을 누릅니다.
 4) /newbot 을 입력해서 보냅니다.
 5) 봇 이름을 묻습니다. 아무거나 입력. 예: 아빠캠핑
 6) 봇 아이디를 묻습니다. 영어/숫자/밑줄(_)만, 반드시 bot 으로 끝나야 합니다. 예: papa_camping_bot (이미 있으면 다른 이름으로)
 7) 성공하면 메시지 안에 1234567890:AAH.... 처럼 생긴 "토큰"이 나옵니다. 길게 눌러 복사만 해 두세요.
    (토큰은 비밀번호입니다. 코덱스에게 알려주는 건 괜찮지만 카톡/문자로 남에게 보내거나 캡처해서 보여주지 마세요. 노출했다면 BotFather에 /revoke)
 8) 방금 만든 봇을 열고(7번 메시지의 t.me/봇아이디 링크) "시작" 또는 /start 를 보냅니다. <- 이걸 안 하면 연동이 안 됩니다.

[C. 컴퓨터와 연결]
 9) Start Camping.bat 로 설치를 먼저 끝냅니다. 설치 중 "텔레그램을 설정할까요? (y/N)" 이 나오면 y 를 누르고 11)부터 진행.
10) 따로 할 때: 이 폴더 위쪽 주소창을 클릭 -> cmd 입력 -> Enter 로 검은 창을 연 뒤 입력:
      .camping-venv\Scripts\python.exe telegram_setup.py
11) 안내에 따라 진행합니다.
      - "교체할까요? YES" 가 나오면 YES 입력 (다른 설정은 지워지지 않습니다)
      - 봇 토큰: 복사한 걸 붙여넣고 Enter. 검은 창에서는 마우스 오른쪽 클릭 = 붙여넣기. 화면에 아무것도 안 보이는 게 정상입니다.
      - "확인된 봇: @봇아이디" 가 나오면 8)을 했는지 확인하고 Enter
      - 대화 목록이 나오면 본인 이름 앞 번호(보통 1)를 입력
      - "테스트 알림을 보낼까요?" -> YES
      - 폰에 "연결 테스트입니다" 가 오면 -> YES (저장)
11-B) [더 쉬운 방법] 코덱스(AI)에게 맡기기
      7)에서 복사한 토큰을 코덱스 채팅에 붙여넣고 "이 토큰으로 연결해줘" 라고 하면, 코덱스가 아래 명령을 대신 실행합니다.
        .camping-venv\Scripts\python.exe telegram_setup.py --token 토큰전체
      (8번 /start 를 먼저 보냈어야 합니다. 성공하면 폰에 "연결 테스트" 메시지가 옵니다. 코덱스에게 알려주는 건 괜찮지만, 카톡 등 다른 사람에게는 보내지 마세요.)
12) (선택) 폰으로 켜고 끄기: 같은 검은 창에서
      .camping-venv\Scripts\python.exe install_remote.py
    폰에서 내 봇에 "도움말" 을 보내 답이 오면 성공. "시작" / "중지" / "상태" 도 보내 보세요. (컴퓨터는 켜져 있어야 합니다.)
13) (선택) 아침 알림: .camping-venv\Scripts\python.exe install_reminder.py

[안 될 때]
 - "개인 메시지가 없습니다" -> 8)을 안 한 겁니다. 봇에 /start 를 보내고 다시 실행
 - "토큰 형식을 확인하세요" -> 토큰 전체(숫자:영문)를 다시 복사. 앞뒤 공백/따옴표 없이
